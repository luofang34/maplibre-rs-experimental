Module celestial 

Source
Expand description

Sun and sky inputs a host supplies in Earth-centred, Earth-fixed axes.

The renderer computes no astronomy: a host works out where the sun is and hands its direction over as an EcefDirection. While none is set, the style’s root light drives the atmosphere as it does without this module.
