§Maplibre-rs

A multi-platform library for rendering vector tile maps with WebGPU.

Maplibre-rs is a map renderer that can run natively on MacOS, Linux, Windows, Android, iOS and the web. It takes advantage of Lyon to tessellate vector tiles and WebGPU to display them efficiently. The headless feature renders supplied tiles into offscreen textures and raster images.

The official guide book can be found here.
