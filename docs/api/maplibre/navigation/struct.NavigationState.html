Expand description

Shared state across input handlers for 2D/3D mode, Auto-Tilt, North-Lock, RTS mode, HUD button interactions, and smooth settle animations.

pub fn ensure_initialized(&mut self, map_context: &mut MapContext)

Captures the style’s initial camera state on the first frame and enables Auto-Tilt by default on 3D terrain and Globe styles.

Source

pub fn pitch_for_zoom(&self, zoom: f64) -> f64

Computes the Auto-Tilt pitch in degrees for a given zoom.

Uses C1-continuous Hermite smoothstep interpolation across zoom stops: 0° at zoom <= 8.5 (overhead globe/regional view), ramping through 22° (z10), 48° (z12), 64° (z13.5), and 74° (z15) up to 78° (z >= 16.5).

Source

Updates the smooth Auto-Tilt target pitch whenever zoom changes.

Source

pub fn process_trackpad_rotate(&mut self, delta_degrees: f64)

Accumulates a trackpad two-finger rotation gesture (WindowEvent::RotationGesture, where delta_degrees is positive for counter-clockwise finger rotation).

Source

pub fn on_manual_tilt(&mut self)

Called when the user manually tilts the camera (e.g. Right-drag, Alt+drag, two-finger vertical drag, or Compass vertical drag). Disengages Auto-Tilt into 3D·MAN mode.

Source

Source

Source

pub fn cycle_3d_mode(&mut self, current_zoom: f64)

Cycles the single 3D/2D/Auto control button:

  • 3D·AUTO -> 2D (smoothly flattens pitch to 0°)
  • 2D -> 3D·AUTO (restores Auto-Tilt pitch, or at least 55° at low zoom so the button always gives visible 3D feedback)
  • 3D·MAN -> 3D·AUTO (re-engages Auto-Tilt along the zoom curve)
Source

pub fn trigger_compass(&mut self, current_bearing: Rad<f64>)

Handles a click on the Compass button: resets bearing to North (0°) if rotated, or toggles north_locked if already facing North.

Source

pub fn trigger_home(&mut self)

Triggers a smooth reset back to the initial HomeCamera view and restores default Auto-Tilt.

Source

pub fn toggle_pointer_profile(&mut self)

Toggles between PointerProfile::Map and PointerProfile::Rts.

Source

pub fn take_pending_smooth_zoom(&mut self) -> Option<f64>

Takes any pending smooth zoom delta queued by HUD +/- buttons or double-click.

Source

pub fn cancel_pitch_animation(&mut self)

Cancels any pending smooth pitch settle animation (for instance when terrain clearance clamps the camera pitch on a steep slope).

Source

pub fn is_animating(&self) -> bool

Whether any smooth camera animation (target_pitch, target_bearing, fly_home) is active.

Source

pub fn wants_frame(&self, view: &ViewState) -> bool

Whether update_frame still moves the camera: an animation runs, or Auto-Tilt is easing the pitch back onto its curve. A host that redraws on demand keeps drawing frames while this holds.

Source

pub fn stop_animations(&mut self)

Stops every running camera animation, leaving the camera where it is, for instance when the host hands the camera to another source.

Source

pub fn set_auto_tilt(&mut self, enabled: bool, current_zoom: f64)

Couples the pitch to zoom along the Auto-Tilt curve, easing onto it, or keeps the current pitch as a manual tilt.

Source

pub fn set_manual_pitch(&mut self, degrees: f64)

Eases to a manually chosen pitch in degrees, leaving Auto-Tilt for 3D·MAN.
