Module navigation 

Source
Expand description

Navigation controls shared by every map host: 2D/3D mode, Auto-Tilt, North-Lock, the RTS pointer profile, HUD button interaction, and smooth camera settling.

A host feeds pointer positions in logical pixels, maps its buttons and gestures onto the NavigationState actions, and calls NavigationState::update_frame once per frame, so the winit and web hosts and embedders that draw their own controls behave the same.
