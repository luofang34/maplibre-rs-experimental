Module coverage 

Source
Expand description

Which DEM tile stands behind each rendered terrain tile, and the elevations they span.

Mirrors GL JS TerrainCoverageIndex: the index is rebuilt every frame from the tiles the terrain draws, so elevation queries, ray casts and tile culling all see the same surface.

The ground at a point is asked one of two ways. The drawn ground, the triangles the frame draws, is DrawnTerrain::ground_at: it decides lines of sight, picking and conversion between the screen and the ground. The best loaded DEM, TerrainCoverageIndex::loaded_ground_cached, reads whatever DEM has loaded, inside the view or not: it keeps the camera and the center above the terrain. Between them sits the crate’s stitched DEM sample, the height the drawn mesh’s vertices take, which the mesh and the flat camera’s gestures are built from.
