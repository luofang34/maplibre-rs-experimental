maplibre::terrain::sightline

Module mesh 

Source
Expand description

The triangles the terrain is drawn with, rebuilt on the CPU where a line of sight needs them.

Each rendered tile is a grid of TERRAIN_MESH_SIZE cells a side, every cell split into two triangles along its diagonal from the north-west to the south-east corner, with vertices at the elevation the tile samples there. The tiles of the first and last row close the globe with a fan from their outer edge to the pole at sea level. Lines are intersected with these flat triangles in unit-sphere space, the chords the GPU draws, not with the curved surface.
