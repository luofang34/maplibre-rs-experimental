pub fn place_anchor_at_pixel(
    view_state: &mut ViewState,
    anchor: TerrainAnchor,
    pixel: Point2<f64>,
) -> bool
Expand description

Moves the center so anchor shows at pixel, keeping zoom, pitch and bearing; the globe turns about its center, carrying the anchor along the sphere at its own height to where the pixel’s ray meets that sphere. Returns whether the anchor reached the pixel.
