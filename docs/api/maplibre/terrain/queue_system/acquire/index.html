Which drapes a frame acquires and draws: textures for its targets, the redraws its time budget holds, and the drape each surface shows meanwhile.

Functions§

acquire_drapes 🔒
awaiting_first_draw 🔒
Tiles whose texture holds no content of their own yet. A new drape the budget deferred would show whatever tile last used the texture, so its surface uses an ancestor or the background color until its own texture is drawn.
budget_redraws 🔒
Which of the acquired drapes to draw this frame, at most budget: tiles never drawn first, since a reused texture shows another tile’s content until they are, then tiles whose content changed.
choose_redraws 🔒
The drapes to draw this frame. Those the view shows take the budget first; a new one with no drawn ancestor would leave its tile blank, so it is drawn past the budget, up to the count a frame’s command buffer holds. Prefetched drapes, which no surface shows yet, draw only with the budget the view leaves and never past it.
