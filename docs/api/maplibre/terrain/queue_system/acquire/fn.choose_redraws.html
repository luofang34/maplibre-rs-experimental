The drapes to draw this frame. Those the view shows take the budget first; a new one with no drawn ancestor would leave its tile blank, so it is drawn past the budget, up to the count a frame’s command buffer holds. Prefetched drapes, which no surface shows yet, draw only with the budget the view leaves and never past it.
