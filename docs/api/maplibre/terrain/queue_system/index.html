Constants§

EYE_DRAPES_PER_FRAME 🔒
Drape textures drawn per frame while a host’s eye drives the map. A flight lands hundreds of tiles within a few frames, and a display’s frame budget holds only a few drapes.
MAX_DRAPES_PER_FRAME 🔒
Drape textures drawn in one frame. Every level of a drape’s mip chain is a render pass, and the Metal backend closes a command buffer per pass that stays open until the frame is submitted, so a burst of arriving tiles must not open more than the queue holds; it also keeps the frame’s GPU time bounded while the rest wait a frame.
