Module drape_share 

Source
Expand description

One allowance of drape textures, divided between the views that drape.

Memory allows a map so many drape textures, and every view holds its own. Were the views to draw from the allowance as they come, the first of a frame would take what it wants and the far tiles of the next would go without a texture and show an ancestor’s. The allowance is instead granted at the start of a frame, by need and in the order of the views’ priority: the first view has the textures it needs to drape its ground uncoarsened, as it would alone, and each view after it has what is left, never less than a floor that keeps its ground draped. A view coarsens its drapes to its grant, so the views together never ask for more textures than there are, whatever the device allows and however many views it draws, and what a view does not need is not kept from the others.
