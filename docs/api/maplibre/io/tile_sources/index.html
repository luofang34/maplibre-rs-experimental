clamp_to_max_zoom
Replaces coordinates deeper than the source’s last zoom with their ancestor at that zoom.
covering_zoom
Zoom level whose tiles cover the view for a source, as GL JS coveringZoomLevel: the map zoom adjusted for the source tile size, rounded for raster sources and floored for vector ones.
missing_tile_fallback
The nearest ancestor to request when the source has no tile at coords, as GL JS retains and loads parents for a tile that answered 404: the walk stops at the first ancestor not known to be missing, and never goes below the source minimum zoom or more than MAX_OVERZOOMING levels up.
outside_source_bounds
Whether every source of this kind that the style draws declares bounds that leave the tile out, so that it is not requested, as GL JS skips tiles outside a source’s bounds.
source_layer_groups
Groups the style layers of one tile kind by the source they read from.
source_max_zoom
The deepest zoom any tile source used by the style has tiles for, which requests are clamped to: a tile at it holds every source, the sources that end sooner cut from their tile at their last zoom. None when a source has no last zoom, so that it reaches every zoom.
source_min_zoom
The shallowest zoom any tile source used by the style has tiles for.
source_tiles_for
Source tiles covering a view tile: itself, its ancestor, or its descendants zoom_delta levels away, kept within the source zoom range. Nothing below the minimum zoom, as in GL JS.
