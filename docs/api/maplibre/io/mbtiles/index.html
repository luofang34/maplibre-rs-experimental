Module mbtiles 

Source
Expand description

Runtime SQLite MBTiles 1.3 archive reader and HttpClient wrapper.

A source names a local archive as mbtiles://path/to/archive.mbtiles (or mbtiles:///absolute/path/to/archive.mbtiles). Fetching the archive URL returns a TileJSON 3.0 document synthesized from SELECT name, value FROM metadata with "scheme": "xyz" and a tile template mbtiles://<archive>/{z}/{x}/{y}. Fetching a tile URL translates XYZ y into MBTiles TMS tile_row = (1 << z) - 1 - y, runs the SQLite query on the CPU worker pool, and transparently decompresses gzip (0x1f 0x8b) or zlib (0x78 ...) vector tiles while leaving PNG, JPEG, and WebP payloads untouched.
