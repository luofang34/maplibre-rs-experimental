Fetches the TileJSON of every tile source that declares a url but no tiles.

A source whose document cannot be fetched or parsed is left unchanged so its layers fall back to the crate default source instead of failing the whole style.

A windowed map does this when its renderer initializes; a headless map’s host awaits it before HeadlessMap::new, passing the kernel’s source client. Nothing in it blocks, so it runs on a browser’s event loop.
