Module cpu_work 

Source
Expand description

CPU-bound tile work, kept off the threads that drive source fetches.

Natively, worker procedures run as tasks on the Tokio runtime’s async threads; decoding and tessellating there holds a thread that other tiles’ fetches are waiting to be polled on. The work runs on the runtime’s blocking pool instead. Browser workers have no such pool and run it inline.
