Expand description

Schedules tile work and receives its tagged results without blocking the render loop. Native implementations can transfer owned Rust values; browser workers can serialize them.

Admits a call without waiting for completion; input or scheduling failures are returned. Procedure failures occur asynchronously and are handled by the selected implementation.

Provided Methods§

Source

fn cancel(&self, _attempt: u64)

Stops the tracked call with attempt if it is still running. A transport that cannot reach its worker lets the call finish; the map ignores a result it gave up on.

Source

fn has_arrivals(&self) -> bool

Whether results arrived that no Self::receive has offered to its consumers yet, so the next frame has something to apply. A transport that cannot tell answers false.

Any receive counts as offering, which holds because every consumer receives in every frame; ask between frames.

Source

fn image_providers(&self) -> Option<&ImageProviders>

The image providers the workers ask, when they share this transport’s memory. A transport whose workers build their own configuration has none to offer here.
