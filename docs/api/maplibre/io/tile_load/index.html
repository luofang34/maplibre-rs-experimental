Module tile_load

Expand description

How each tile’s requests stand, as GL JS Tile.state, and which tiles are loading.

A request family marks a tile loading when it admits a request for it and settled when the request’s outcome lands or the request is given up. The tiles marked loading are kept in a set, so counting them reads that set instead of every tile.
