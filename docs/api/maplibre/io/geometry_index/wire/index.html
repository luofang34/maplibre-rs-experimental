maplibre::io::geometry_index

Module wire 

Source
Expand description

Struct-of-arrays wire encoding of TileIndex for single-threaded worker transport.

Multipart features without an explicit feature id share an Arc<FeatureProperties> pointer across their geometry parts so query_rendered_features deduplicates them as one feature. WireTileIndex deduplicates property maps by Arc pointer into prop_offsets / prop_blobs and interns source_layer strings into strings, preserving Arc sharing across FlatBuffer serialization boundaries with a constant number of vector allocations per tile.
