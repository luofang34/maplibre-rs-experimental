Expand description

Poses of glyphs whose centres lie offsets screen pixels (signed, along the text) from the anchor at anchor_distance along polyline, as project shows the line. flip reads the text against the line, each glyph walking the other way and turning half way around. A pose’s point and angle are the tile-unit point on the line and the tile-unit direction of the segment it lies on, the way the text reads. None when a glyph would lie beyond either end of the visible line.
