Module line_anchors 

Source
Expand description

Anchors for labels that follow a line: evenly spaced along it, kept off sharp bends, and offset so the repeats of a line that crosses tiles stay consistent.

Lengths are tile units; the caller converts pixels with the tile’s pixel ratio.
