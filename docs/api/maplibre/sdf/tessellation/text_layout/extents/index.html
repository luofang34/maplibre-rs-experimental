The boxes a label takes: its layout extent, how far its variable anchors move it, and its width without wrapping.

Functions§

both_orientations 🔒
The two ways a point label whose style allows both is written, as [first, second] with true for vertical; None for a text with one.
extent 🔒
The label’s layout box [left, top, right, bottom] around the anchor, in layout pixels.
is_vertical 🔒
Whether the label is written top to bottom, which turns the whole symbol a quarter clockwise.
layout_extent 🔒
The label’s layout box [left, top, right, bottom] before a vertical label turns, in layout pixels.
unwrapped_width 🔒
Width in layout pixels of the label on one line, without wrapping; zero without glyphs.
variable_shifts 🔒
How far the label moves, in layout pixels, when it takes each of its variable anchors instead of the first; empty unless the label has several.
