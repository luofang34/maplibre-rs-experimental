PERSPECTIVE_RATIO_CUTOFF 🔒
GL JS’s perspectiveRatioCutoff: a label whose anchor lies so far beyond the view centre that the camera’s perspective would draw it at less than this ratio of its size is not placed, so labels do not crowd the horizon of a pitched map.
