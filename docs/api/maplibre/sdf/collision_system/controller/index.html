maplibre::sdf::collision_system

Module controller 

Source
Expand description

Throttles screen-space symbol collision passes to discrete placement epochs.

Matches MapLibre Native / GL JS placement cadence:

  • Continuous camera motion places at most every 250 ms (~4 Hz).
  • Newly uploaded symbol buckets, style/terrain surface updates, integer zoom crossings, and repeat-spacing settle passes debounce at 30 ms.
  • Stationary settled views run at 0 Hz (0 placement passes, 0 GPU buffer writes).
  • Deterministic PlacementConfig::immediate() (fade_duration == Duration::ZERO) places on every view or content change without throttling.
