Expand description

Layers GL JS groups into one symbol bucket share one placement.

GL JS builds one bucket for style layers alike in type, source, source layer, zoom range, filter and layout, and only the lowest of them places it. The others draw that bucket with their own paint and the same placement, so they neither collide with one another nor with the lowest, and a query finds a placed label in each of them.
