Dirty sub-range diffing and coalesced GPU uploads for SDFShaderFeatureMetadata.

Newly allocated symbol buckets are zero-initialized in GPU memory (SDFShaderFeatureMetadata::default()). During a PlacementEpoch, most symbols in a tile either stay clean or remain hidden, so diffing per-vertex metadata and uploading only coalesced dirty runs eliminates ~90% of queue.writeBuffer bandwidth compared to rewriting entire bucket allocations.
