Module provider 

Source
Expand description

Images made on request for the names a style asks for, such as road shields drawn from a route’s network and number, so that no host has to list every image in advance.

A host registers a StyleImageProvider under a namespace. A name of the form namespace:id that neither the sprite nor the style’s own images supply is then asked of that provider, from the tile worker that lays the label out, never from the render thread. The label is drawn at once with whatever the style falls back to and laid out again when the image arrives. The style itself only names images, so it still serializes; the provider lives in the runtime, beside the worker’s other services.
