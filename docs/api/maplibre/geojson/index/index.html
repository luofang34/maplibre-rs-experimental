maplibre::geojson

Module index 

Source
Expand description

A GeoJSON document parsed once into a spatial index, tiled into vector tile bytes on demand.

Tiles are cut from the index instead of re-reading the document, so a source is parsed once per generation however many tiles are requested. Geometry is not clipped or simplified: the tile boundary is applied by the renderer’s stencil.
