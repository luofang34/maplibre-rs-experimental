Module dynamic_points 

Source
Expand description

In-place GPU metadata fast path for stationary dynamic-point GeoJSON circle sources.

When a GeoJSON FeatureCollection of Points keeps identical feature IDs and coordinates across updates (such as real-time sensor telemetry), this module parses incoming UTF-8 JSON directly into FeatureProperties without serde_json::Value DOM allocation, skips bumping source.generation / style.revision() (zero worker re-tiling), and updates only visible tiles’ [fill_rgba8, packed_radius_f16x2] GPU feature metadata in-place.
