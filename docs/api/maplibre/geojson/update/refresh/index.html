maplibre::geojson::update

Module refresh 

Source
Expand description

Fetching again only the loaded tiles that new GeoJSON data changes.

A tile holds the features whose bounds meet its window, the tile and the index’s buffer around it, and its content is made from those features alone: line widths, labels and the source’s own buffer act on them inside the tile. So a feature’s change reaches exactly the tiles whose window meets its old or its new bounds, at each tile’s own zoom, and the other tiles would come back unchanged.
