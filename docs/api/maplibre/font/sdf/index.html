Module sdf 

Source
Expand description

Signed Distance Field (SDF) glyph rasterisation matching MapLibre’s 24px PBF glyph metrics.

Uses skrifa to extract unhinted outlines at 24.0 px, ab_glyph_rasterizer for subpixel coverage, and the 2D Felzenszwalb & Huttenlocher Euclidean distance transform (TinySDF subpixel boundary seeding) with buffer = 3, radius = 8.0, and cutoff = 0.25 (0.75 inside-edge threshold in sdf.fragment.wgsl).
