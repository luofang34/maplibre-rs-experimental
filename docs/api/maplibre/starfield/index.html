Module starfield 

Source
Expand description

Stars behind the globe, drawn from the directions, magnitudes and colours a host sets with crate::context::MapContext::set_stars.

Stars lie at infinity: the globe’s view-projection carries their directions with w = 0, so they turn with the camera and never move with it. They are drawn first in the main pass at the far plane and test depth without writing it, so the globe, its terrain and every layer cover them. A globe whose style paints nothing on it, with no background and no terrain, shows the stars through its disc.
