Module circle 

Source
Expand description

Whether a query meets a circle, as GL JS CircleStyleLayer.queryIntersectsFeature decides it: within the circle’s radius and stroke of its centre, measured on the screen for a circle that faces the viewport and on the ground for one that lies on the map, scaled by how far the centre is from the camera when the circle’s size follows the other plane.
