Module query 

Source
Expand description

Features under a screen point or box, as GL JS queryRenderedFeatures.

Symbols come from the latest placement pass. Fill and line features come from the geometry index each worker builds for a tile; style layers are resolved against the live style at query time, so filters, visibility, paint edits and layer removal never leave the index stale.
