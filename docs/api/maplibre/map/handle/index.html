maplibre::map

Module handle 

Source
Expand description

A host reaches a running map through commands that whoever owns the map applies between frames, so nothing borrows the map while a frame or an input handler holds it, and the map can be suspended, reset or rebuilt without invalidating the host’s handles.

The owner keeps MapCommands next to its Map and calls MapCommands::apply when woken, MapCommands::observe after each frame and MapCommands::close when it stops. Any host fits: a winit loop, a view driven by the platform’s display link, or a headless test.
