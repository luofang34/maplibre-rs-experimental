maplibre::overlay

Module probes 

Source
Expand description

Depth probes: whether points a host draws over the map, outside its frame (text, icons), lie behind what the frame drew there.

The probes go to the GPU with a frame, which compares each against the frame’s depth at its pixel, as the overlay pass compares its vertices; the answers are read back without waiting, and arrive a frame or two later. One request is in flight at a time; probes set meanwhile wait for it, the latest replacing earlier ones.
