Module hud 

Source
Expand description

Cross-platform GPU navigation HUD overlay and tactical selection rectangle.

Renders a compact floating control capsule in the top-right safe area of the viewport (3D compass with north-lock, 3D/2D + AUTO/MAN tilt toggle, +/- zoom buttons, Home reset, and MAP/RTS pointer profile switch), plus an optional rubber-band selection box when dragging a box selection in RTS or Shift+drag mode.
