Expand description

Platform-neutral gesture recognizer and camera controller.

Handles pointer drag pan, multi-touch 1-finger pan and 2-finger pinch-zoom / twist-rotate / parallel-drag pitch, scroll-wheel and trackpad zoom/pan/orbit, double-click and double-tap smooth zoom, keyboard navigation, HUD capsule interaction, and kinetic pan/zoom/rotate inertia.
