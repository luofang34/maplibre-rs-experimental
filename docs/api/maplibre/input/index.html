Module input 

Source
Expand description

Window-system-independent gesture recognition and camera input state machine.

Hosts translate their native UI events (winit, UIKit, Android MotionEvent, Web DOM, or custom embedded surfaces) into InputEvent values in logical window pixels and feed them to InputController::handle_event, then advance UpdateState::update_state (or InputController::update_view) once per frame.
