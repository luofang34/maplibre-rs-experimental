global-state: values set once on the style that expressions of any layer can read.

An expression is resolved when its value changes: the layer as declared is kept, every ["global-state", key] in its filter and properties is replaced by the key’s current value, and the layer is parsed again. Evaluation therefore needs no extra input, and a layer that reads no state is never touched.
