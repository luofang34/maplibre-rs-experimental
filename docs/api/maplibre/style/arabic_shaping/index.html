Module arabic_shaping 

Source
Expand description

Arabic letters in the joined forms they take in a word, as Unicode’s presentation forms.

Text is shaped before glyphs are requested and before it is laid out, the way GL JS applies its RTL plugin, so each form is a character of its own with the advance of its own glyph.
