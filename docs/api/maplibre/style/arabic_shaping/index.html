Arabic, Persian, Urdu, and extended Arabic contextual shaping into Unicode presentation forms.

When an OpenType font face is loaded, crate::font runs full GSUB/GPOS shaping via harfrust. When only legacy .pbf SDF glyph ranges are available, this module maps Unicode U+0600..U+06FF letters into their isolated, final, initial, and medial presentation forms (U+FB50..U+FDFF and U+FE80..U+FEFC), handles U+0640 Tatweel and ZWJ/ZWNJ, and forms Lam-Alef ligatures across intervening tashkeel diacritics.
