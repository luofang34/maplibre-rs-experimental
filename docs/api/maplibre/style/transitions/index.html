Module transitions 

Source
Expand description

Declarative *-transition timing and runtime paint property interpolation.

Freshly deserialized styles draw their declared paint values immediately without initial fade-in. Subsequent Style::set_paint_property and Style::diff_and_replace mutations interpolate smoothly when the target property’s layer <prop>-transition (or root Style::transition) specifies a positive duration or delay.
