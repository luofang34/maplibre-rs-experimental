Expand description

A type a style property can hold, with the specification the expression engine needs to lower legacy syntax into it.

Required Methods§

Source

fn spec() -> LegacyPropertySpec

What the specification says about properties of this type.

Source

fn from_value(value: &Value) -> Option<Self>

The value an expression produced, if it fits this type.

Provided Methods§

Source

fn from_literal(_json: &Value) -> Option<Self>

A constant written directly in the style that the expression engine would not accept as this type, such as an array of colour strings; None hands the JSON to the engine.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
