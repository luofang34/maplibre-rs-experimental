    pub(super) key: String,

Expand description

Parser state: the path being parsed and the variables in scope.

Fields§

§key: String§scope: Vec<(String, Expression)>§null_fallbacks: bool

Whether a null literal may stand where a typed value is expected. A lowered legacy function without a default falls back to null, which evaluates to nothing so the caller applies the property’s own default; user-written expressions stay strict.
