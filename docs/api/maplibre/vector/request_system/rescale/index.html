Module rescale 

Source
Expand description

Cutting a tile from the last tile a source has above it.

A source whose tiles end at a zoom is drawn at finer zooms from its tile at that zoom, as GL JS draws an overscaled tile. A tile here holds every source at once, so instead the ancestor’s features are brought into the finer tile’s own grid, scaled and shifted, with what lies beyond the tile and its buffer cut away; the tile is then drawn at its own zoom like the tiles of the sources that reach it.
