Expand description

Decodes only the layers accepted by layer_keys, pruning MVT property tables to referenced keys where layer_keys returns Some(Some(keys)) and optionally clipping features into a descendant tile’s extent during decoding. Falls back cleanly for non-MVT or malformed tiles.
