Expand description

Scans raw MVT protobuf wire tags (Tile.layers = 3, Layer.name = 1) and decodes only layers accepted by layer_keys:

  • None: skip the layer completely;
  • Some(None): decode the full layer including all properties;
  • Some(Some(keys)): decode geometries and only the MVT keys present in keys.

When rescale is Some((from, to)), each decoded feature is clipped into to’s descendant extent before its referenced properties are materialized. Returns None when data is empty, non-MVT (e.g. MLT), or fails wire validation so the caller can fall back cleanly.
