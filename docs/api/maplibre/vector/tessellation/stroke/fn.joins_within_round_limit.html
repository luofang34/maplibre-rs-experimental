pub(crate) fn joins_within_round_limit(path: &Path, round_limit: f32) -> bool
Expand description

Returns true when path has at least one interior join and every join’s miter ratio (1 / sin(half_angle)) is at or below round_limit, allowing LineJoin::Round to collapse to shallow miter joins with StrokeOptions::with_miter_limit(round_limit).
