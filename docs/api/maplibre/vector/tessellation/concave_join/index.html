Module concave_join 

Source
Expand description

Splits unbounded concave miter vertices emitted by lyon_tessellation.

lyon_tessellation evaluates segment-folding heuristics against half_width in tile units (0.5 by default), whereas line and fill-outline shaders extrude vertex normals in screen pixels (line-width or 1 px) independent of tile-to-screen zoom. On sharp < 1° coastal zig-zags whose edges exceed 0.5 tile units yet remain shorter than the screen-space miter reach, lyon leaves the concave (back_side) corner as an un-folded single miter vertex with |normal| = 1 / sin(theta / 2), producing long spikes without pinching only if split into two segment-perpendicular vertices (inner_join).
