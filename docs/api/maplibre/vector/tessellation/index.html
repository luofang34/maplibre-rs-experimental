Functions§

circle_pack_colors
Two colours, straight RGBA in 0..=1, in the four lanes of one feature colour: each lane holds two 8-bit channels as -(256 a + b) - 1, which an f32 keeps exactly, as GL JS packs colours. The vertex slots of a circle are all taken, so a stroke colour that varies by feature shares the lanes of the fill’s. A plain colour is never negative, so the sign tells the shader which a vertex holds, whatever the layer’s style says now: a tile built before a paint change keeps drawing as it was built until its replacement arrives.
