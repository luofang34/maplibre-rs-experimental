Module circle

Expand description

Circle layers: one screen-aligned quad per point, extruded by the shader.

Each quad’s vertices carry the feature’s radius and stroke width in the normal slot; the shader recovers the corner direction from the vertex index, so both values can be data driven. Points outside the tile are skipped as GL JS does, since a neighbouring tile draws them.
