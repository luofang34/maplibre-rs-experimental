Module sharp_corners 

Source
Expand description

Keeps the shear of a sharp corner short.

The vertices a join adds are displaced along the line, but carry the distance of the corner itself, so a distance-driven dash, pattern or gradient slants across the whole segment that ends in the corner. A point a few units before and after each sharp corner confines the slant to that stretch, as GL JS’s line bucket does.
