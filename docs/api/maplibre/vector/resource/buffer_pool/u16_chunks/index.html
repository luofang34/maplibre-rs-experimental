Module u16_chunks 

Source
Expand description

Greedy u16 sub-chunking for large (> 65,536 vertices) index buffers when [wgpu::DownlevelFlags::BASE_VERTEX] is supported.

Constants§

MAX_U16_CHUNKS 🔒
Maximum number of contiguous base_vertex chunks per layer before falling back to u32 indices, preventing draw-call explosion on wildly non-local triangle streams.

Functions§

layer_allows_u16_chunks 🔒
Returns true when style_layer can safely emit multiple draw_indexed sub-ranges without colliding with sort_runs (circle) or per-feature pattern_runs.
plan_u16_chunks 🔒
Attempts to partition u32_slice[..usable] triangles into contiguous (base_vertex_offset, index_range) chunks whose local index span fits in u16.
write_chunked_u16_indices 🔒
Writes chunks into scratch, subtracting each chunk’s v_off so every index fits in u16.
