Structs§

CoveringRequest
Which tiles a covering asks for: the nominal level, the fractional zoom the distance rule starts from, and the rounding and zoom range of the source the tiles come from. The view and vector sources use the map zoom floored; a raster source adjusts the zoom for its tile size and rounds, as GL JS gives every source its own tile manager.

globe_center_references 🔒
The centre the shaders project globe positions relative to: the f32 Mercator position nearest the globe camera’s centre on the ground, with its clip position and body-centre vector computed in f64. Positions built from global f32 coordinates round to metres, which a close view of the globe draws as geometry that slides; relative to this centre they keep their separation.
