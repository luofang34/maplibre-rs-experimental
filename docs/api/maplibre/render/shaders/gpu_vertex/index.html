Module gpu_vertex 

Source
Expand description

Compact 16-byte GPU vertex encoding (GpuShaderVertex) for vector tile pipelines.

CPU tessellation and spatial-elevation systems operate on 32-byte f32 ShaderVertex records, while BufferPool packs them into 16-byte GpuShaderVertex words on upload (-50% vertex VRAM and PCIe/WebGPU writeBuffer bytes).
