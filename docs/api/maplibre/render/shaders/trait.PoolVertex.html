Expand description

Maps a CPU vertex type Self to its GPU-resident storage representation Self::Gpu.

Required Associated Types§

Source

type Gpu: PodTrait + Debug

GPU vertex record uploaded to the vertex slab.

Required Methods§

Source

fn encode_vertices<'a>( layer_type: &str, src: &'a [Self], scratch: &'a mut Vec<Self::Gpu>, ) -> &'a [Self::Gpu]

Returns src in Self::Gpu form, either by zero-copy slice borrow or by packing into scratch.

Provided Methods§

Source

fn encoding_family(layer_type: &str) -> u8

Returns a compact tag identifying which GPU bit-layout layer_type produces, so shared source-layer vertex slabs only alias across compatible shader families.

Source

fn vertex_element_alignment(layer_type: &str) -> u64

Required alignment of first_vertex in elements (4 for quad-indexed shaders that decode corners via @builtin(vertex_index) % 4u, 1 otherwise).

Source

fn can_encode_compact_extrusion(layer_type: &str, src: &[Self]) -> bool

Returns true when src fits losslessly in the compact 8-byte extrusion format.

Source

fn try_encode_compact_extrusion<'a>( layer_type: &str, src: &'a [Self], scratch: &'a mut Vec<Self::Gpu>, ) -> Option<&'a [Self::Gpu]>

Packs src into two 8-byte compact extrusion vertices per Self::Gpu word when eligible.
