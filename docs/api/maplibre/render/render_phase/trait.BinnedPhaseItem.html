Expand description

Phase item constructed on the stack per merged batch during BinnedRenderPhase::render.

Mirrors Bevy’s BinnedPhaseItem: individual queued instances are stored compactly inside reusable bins rather than materialized as full BinnedPhaseItem structs during Queue.
