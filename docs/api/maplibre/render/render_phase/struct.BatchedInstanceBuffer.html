Expand description

Contiguous CPU/GPU instance buffer for BD, supporting storage buffers, vertex-step instance buffers, and aligned dynamic uniform fallback buffers.

Mirrors Bevy’s BatchedInstanceBuffer<BD>. Packed storage/vertex backing (gpu_buffer) and dynamic-uniform backing (uniform_gpu_buffer) are maintained independently so multiple phases sharing BD with different FallbackInstanceBufferModes never clobber each other.
