Module memory_budget 

Source
Expand description

What the host’s memory lets a frame keep.

A headset can terminate memory-heavy processes. A flight to the ground brings a hundred drawn tiles, each with a drape texture, and a burst of tile uploads, and that alone can carry the footprint past the limit. The host reports how much memory is still available each frame; below a reserve the frame goes carefully: only the nearest tiles keep a drape texture of their own and the rest draw with an ancestor’s, spare textures are released, and tiles are requested a few at a time; nearly out, nothing new is taken on and every tile out of view is dropped. A hard cap on drape textures holds even when the host reports nothing.
