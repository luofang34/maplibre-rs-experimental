Module eye_covering 

Source
Expand description

One tile covering for both eyes of a frame.

Tile selection and content ingestion happen once per stereo frame. Each eye then draws that selection with its own projection, so a tile cannot change level or content between the left and right images.

Structs§

EyeInFrame
Which eye of a frame the schedule is running for.
FrameLodHistory 🔒
The tiles the previous frame drew, per covering, as one immutable snapshot every request and draw of this frame selects against. Each covering keeps its own history: the terrain surface, the view and each raster source split the quadtree at different levels, so one covering’s leaves say nothing about where another split.
SharedCovering
The drawn tiles a frame selected: the first eye’s, which later eyes of the frame reuse, or the map camera’s own.

The tiles the frame draws at level, with the raster tiles each raster source draws: the first eye’s selection when the schedule runs for a later eye of the same frame, and otherwise this view’s own, kept as the next frame’s level history.
drawn_tiles 🔒
The tiles the frame’s covering selected, each once, or None before a covering is selected or when it selected no region.
snapshot_lod_history 🔒
Takes the snapshot for the frame about to select tiles. Every camera gets it, not only a host’s eye: a map camera that moves a little each frame would otherwise switch a tile sitting on a level threshold between its fine and coarse version frame after frame.
