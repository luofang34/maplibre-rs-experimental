Drag and zoom on a free-globe camera, which turn the camera about the body’s center and so carry it over a pole as anywhere else.

Constants§

ANCHOR_PASSES 🔒
Corrections that bring a zoom’s anchor back under its pixel.
ZOOM_HALVINGS 🔒
Times a zoom step that leaves no drawable camera is halved before the zoom stops, which brings it within a thousandth of the step of the last distance a camera can be drawn from.
