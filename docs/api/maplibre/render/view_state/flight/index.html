The path an animated camera move takes, as GL JS easeTo and flyTo draw it on the globe.

A path gives the CameraOptions a move shows at each point of its progress; a jump to them places the camera, in either navigation mode, so a move and a jump agree on where the camera stands and how high its center rests.
