Camera pose: where the camera stands and where it looks.

The view state keeps the map center, zoom and angles, as GL JS does. A pose gives the camera’s own ground position and altitude instead, the form a tracker or a flight path provides. Converting a pose into center and zoom keeps tile covering and pixel scale consistent with the map’s own gestures, as GL JS calculateCenterFromCameraLngLatAlt and getCameraLngLat do.
