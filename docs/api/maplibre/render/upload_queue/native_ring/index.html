Module native_ring

Expand description

Native persistent MAP_WRITE | COPY_SRC staging ring for UploadQueue.

Avoids per-frame wgpu::Queue::write_buffer staging allocations and (wgpu internal) PendingWrites blit command buffers on native non-GL backends by writing staged bytes directly into mapped ring chunks and encoding copy_buffer_to_buffer transfers into the frame encoder.
