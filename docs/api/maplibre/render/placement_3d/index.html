Module placement_3d 

Source
Expand description

Full 6-DoF geodetic + quaternion placement contract and per-slot visibility mask for dynamic 3D entities rendered in crate::render::draw_graph::node::SCENE_3D_PASS.

Coordinate conventions:

  • Local tangent frame (ENU, metres): +X East, +Y North, +Z geodetic Up.
  • Body frame (Body, metres): right-handed, ENU-aligned at zero attitude: +X right wing / starboard, +Y forward / nose, +Z dorsal / up.
