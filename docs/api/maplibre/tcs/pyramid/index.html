Module pyramid 

Source
Expand description

Hierarchical tile pyramid with O(1) zoom-level bitmasks and contiguous Morton subtrees.

Modeled after maplibre-native TilePyramid and maplibre-gl-js SourceCache, adapted to Rust with per-zoom-level MSB-first 64-bit Morton BTreeMaps and a 32-bit zoom_mask. Because standard Morton interleaving places every descendant of (x, y, z) at level z + d inside one exact contiguous key range [base ..= base | ((1 << 2d) - 1)], ancestor walks skip empty levels in O(1) via bit-scans and descendant subtree checks avoid probing 4^d missing child coordinates.
