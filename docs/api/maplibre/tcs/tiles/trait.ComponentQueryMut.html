Expand description

Component lookup with exclusive access to the tile store while constructing the result. Built-in tuples may mix shared and mutable references to disjoint component types.

Required Associated Types§

Source

type MutItem<'t>

Value returned with a lifetime bounded by the exclusive tile-store borrow.
