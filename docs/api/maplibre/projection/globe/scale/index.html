Module scale

Expand description

Style zoom on a globe whose camera may look at any point, the poles included.

The camera’s physical scale is the globe’s radius in screen pixels. Style zoom, which ["zoom"] expressions, layer zoom ranges and the integer layout zoom read, stays what the Mercator world defines wherever that world reaches: the zoom of the world whose parallel at the center’s latitude has the globe’s circumference. Past the Mercator world’s last latitude the parallel is taken at that latitude, so near a pole the style zoom follows the physical scale without running off to minus infinity as the parallel shrinks to a point, and a camera crossing the pole sees it change continuously and symmetrically.
