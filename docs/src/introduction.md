# Introduction

maplibre-rs is a portable and performant vector and raster maps renderer.

This book documents the [experimental fork](https://github.com/luofang34/maplibre-rs-experimental) of
[maplibre-rs](https://github.com/maplibre/maplibre-rs). Its API documentation is published
[alongside this book](https://luofang34.github.io/maplibre-rs-experimental/docs/api/maplibre/).


## Name

The name of the library is "maplibre-rs". The camel-case version of it is "MapLibreRs".
